# DAP Todo

[DAP (Desk AI Pet)](https://github.com/Project-Undonghae/desk-ai-pet) 플러그인. 할 일을
**칸반**으로 관리하고, 붙여넣은 글·이미지·메일에서 **할 일 초안을 뽑아 확인 후**
등록한다. 등록된 할 일은 DAP의 대화 맥락으로 들어가서, "오늘 뭐부터 하지?"에 DAP이 답할 수 있다.

## 기능

- **칸반** — `Inbox → 할 일 → 진행 중 → 완료` 를 드래그로 옮긴다. 새로 들어온 것과 "일단 넣어둔 것" 은
  Inbox 에 모였다가 사용자가 훑어 올린다. 안 하기로 한 카드는 우측 하단 **보관함**으로 끌어다 놓는다
  (지우지 않고 옮기므로 되돌릴 수 있다).
- **이번 주 할 것** — 이번 주 마감이거나 중요한 건을 보드 위에 접었다 폈다 하는 목록으로 먼저 보여준다.
- **자동 추출** — 세 가지 입력에서 할 일 초안을 만든다.
  | 입력 | 방법 |
  |---|---|
  | 붙여넣기·복사한 글 | 클립보드 텍스트를 그대로 분석 |
  | 이미지 | 스크린샷·사진 속 글자에서 추출 |
  | 메일 | 사용자 CLI에 연결된 Gmail 커넥터로 최근 메일 확인 |
  추출 결과는 **항상 확인 카드를 거친다.** 자동 등록은 없다.
- **마감 알림** — 마감이 다가오면 DAP이 말풍선으로 알린다 (기본 10분 전, 설정에서 조절).
- **아침 브리핑** — DAP 설정에서 브리핑을 켜면 오늘 할 일을 하루 한 번 알려준다.
- **트레이 위젯** — 트레이 허브에서 오늘 할 일 5건을 바로 확인하고 체크.

## 설치

DAP 설정 ▸ 플러그인 ▸ 카탈로그에서 **Todo** 설치. git이나 빌드 도구가 필요 없다.

요구 버전: **DAP 1.4.0 이상** (`ctx.briefing` 슬롯을 쓴다).

## 권한

| 권한 | 쓰임 |
|---|---|
| `storage.private` | 할 일 목록을 이 플러그인 전용 폴더에 저장 |
| `window.palette` | 할 일 창과 트레이 위젯 표시 |

메일·이미지 분석은 DAP에 이미 연결된 AI(사용자 본인의 Claude/Codex 구독)를 쓴다. 이 플러그인은
별도의 계정 연결이나 API 키를 요구하지 않는다.

## 알아둘 점

- 마감 알림과 브리핑은 **DAP이 켜져 있는 동안만** 동작한다. 절전·종료 중에는 알리지 못한다.
- 이미지 추출은 AI provider에 따라 결과가 다르다. Codex 제공자에서 가장 안정적이다.
- 메일 추출은 사용자 CLI에 Gmail 커넥터가 연결돼 있어야 한다.

## 개발

```bash
node scripts/check.mjs   # 매니페스트·UI 문법·순수 로직 검증
```

로컬 설치는 이 폴더를 `%APPDATA%\dap\plugins\io.github.o-min222.todo\`
(macOS는 `~/Library/Application Support/dap/plugins/…`)에 두고 DAP을 재시작한다.
